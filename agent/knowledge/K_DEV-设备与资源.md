# 文件系统与设备管理

设备、文件描述符、映射、DMA 缓冲等都是有限资源。申请后若在错误路径不释放，会泄漏句柄或让设备卡在忙状态；正常路径也要在生命周期结束时关闭。

## RESOURCE_NOT_CLOSED 资源未释放或出错分支未清理

打开了设备/文件、映射了内存、申请了驱动侧缓冲，却在失败返回或任务退出时没有 close/unmap/free。多次发生会耗尽资源表，后续打开失败。

MiniEuler 场景更多是“软件资源”：信号量、任务、中断注册、串口回调。创建成功后的半截初始化若失败，需要按相反顺序拆掉已注册部分。

改法：每个获取操作配对释放；错误路径 `goto cleanup`；模块卸载/任务退出走统一析构；检查中断注册与解除是否对称。

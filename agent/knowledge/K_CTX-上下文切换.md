# 进程控制块与上下文切换

任务切换要保存当前任务“恢复执行所需的全部架构状态”，再装入下一个任务的状态。保存不全会导致返回用户/内核路径后寄存器错乱、偶发数据损坏或异常。

## CONTEXT_SAVE 上下文保存不完整

切换时漏存或漏恢复必要寄存器。ARMv8 上除通用寄存器 `x0–x30`、栈指针外，通常还要考虑 `ELR`/`SPSR`、条件标志，以及若任务使用浮点/SIMD 时的 `q` 寄存器与 FPSR/FPCR。只保存一部分通用寄存器却假定“其它不会用到”，在编译器生成浮点代码或其它任务用到 FP 时会踩坑。

MiniEuler 的向量/切换汇编（如 `prt_vector.S` 一类）和任务栈初始化要一致：创建任务时写入的初始上下文布局，必须与切换代码保存/恢复的布局相同。

改法：对照架构手册列出切换帧字段；汇编与 C 侧 TCB/栈帧定义一致；若声明不保存 FP，则确保全内核与任务都不使用 FP，或在切换路径完整保存。
